# Contrato de serviço

1. Colete dados das partes, escopo, valor, forma de pagamento, prazo, revisões, manutenção e foro.
2. Não invente dados ausentes; apresente campos pendentes ao usuário.
3. Gere documento versionado e verifique se nenhum placeholder permaneceu.
4. Solicite revisão jurídica antes do uso definitivo.
5. Não envie nem assine em nome do usuário.
6. Após confirmação, atualize `contratoStatus` para pendente, enviado ou assinado.
