# Configuração do Search Customers

1. Confirme que Node.js 22+ e as dependências estão instalados.
2. Pergunte nome comercial, apresentação, e-mail, WhatsApp, cidade e nichos prioritários.
3. Defina os critérios mínimos de nota, avaliações e quantidade por busca.
4. Nunca solicite ou grave credenciais em arquivos versionados.
5. Inicie o dashboard com `npm run dev` e confirme a API em `/api/health`.
6. Oriente o usuário a instalar Google Maps Platform e Playwright quando desejar automatizar a pesquisa.
