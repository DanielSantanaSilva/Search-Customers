# Publicação segura

1. Confirme o lead, os arquivos e o destino antes do upload.
2. Prefira SFTP ou FTPS; não use FTP sem criptografia.
3. Obtenha credenciais por variável de ambiente ou cofre do sistema, nunca pelo repositório.
4. Faça backup quando substituir arquivos existentes.
5. Verifique HTTPS, status HTTP, assets, responsividade e links após publicar.
6. Registre a URL no CRM e altere o status para `publicado` somente após a verificação.
